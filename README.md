Компілятор SIGNAL: Лексичний, синтаксичний аналіз та генерація коду

Лабораторна робота №1 — Розробка лексичного аналізатора

Мета: створити лексичний аналізатор для мови SIGNAL.

Функціонал:
- Зчитування тексту програми та розпізнавання лексем
- Виявлення констант, ключових слів, ідентифікаторів і роздільників
- Видалення коментарів у форматі (* ... *)
- Формування таблиць ідентифікаторів та констант
- Генерація файлу tokens.txt зі структурованим потоком лексем
- Виведення повідомлень про лексичні помилки

Розрахунково-графічна робота — Розробка синтаксичного аналізатора

Мета: реалізувати синтаксичний аналізатор для граматики SIGNAL на основі рекурсивного спуску.

Функціонал:
- Зчитування лексем із tokens.txt
- Побудова дерева розбору в процесі аналізу
- Формування повідомлень про синтаксичні помилки з точним місцем у коді
- Збереження дерева у вигляді текстового файлу tree_output.txt

Лабораторна робота №2 — Розробка генератора коду

Мета: реалізувати генератор коду на основі дерева розбору.

Функціонал:
- Зчитування дерева з tree_output.txt.
- Вивід внутрішнього представлення коду у вигляді асемблерних інструкцій.
- Підтримка генерації коду для:
  - оголошення та ініціалізації констант 
  - стандартного завершення програми 
- Побудова структури data та code сегментів.
- Формування фінального файлу output.txt.
